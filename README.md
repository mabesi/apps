# Mabesi Apps

**Portfolio of Open Source Projects by Plínio Mabesi**

This repository contains the source code for the Mabesi Apps portfolio website, showcasing a collection of free, open-source applications developed by Plínio Mabesi. The portfolio features projects across various categories including finance, utilities, productivity, education, and tools.

All projects are maintained with dedication and built for the community, without ads or hidden costs.
